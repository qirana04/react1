# SwiftConvert - Premium Unit & Currency Converter

A modern, offline-first unit and currency converter built with React.

## Features
- **Offline Currency Conversion**: Preset rates for major currencies.
- **Unit Conversion**: Length, Weight, and Temperature.
- **Glassmorphism Design**: Beautiful, modern UI with indigo accents.
- **History**: Saves your recent conversions locally.
- **Responsive**: Works on desktop and mobile.

## How to Run
1. Open terminal in this directory.
2. Run `npm install`
3. Run `npm install framer-motion lucide-react`
4. Run `npm run dev`
